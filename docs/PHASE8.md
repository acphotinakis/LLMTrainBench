# Phase 8 Evaluate Hardware

## Purpose

Optionally determine whether core findings replicate on NVIDIA hardware without mixing platform effects with method effects.

## Tasks

- Complete the Mac core study first.
- If NVIDIA hardware is obtained, freeze its environment and cost before running.
- Repeat one complete comparison using identical within-platform conditions.
- If two identical GPUs are available, optionally run one-GPU versus two-GPU DDP.

## Exit Criteria

- Mac and NVIDIA results are separate strata.
- Every within-platform comparison holds hardware fixed.
- Multi-GPU scaling reports throughput, global batch policy, and scaling efficiency.

## Outputs

Optional hardware protocol amendment, platform-specific results, cost comparison, and scaling analysis.
